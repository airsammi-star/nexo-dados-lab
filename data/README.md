# Dados

Use somente dados públicos, sintéticos ou anonimizados. Para cada fonte, registre:

- endereço e responsável pela publicação;
- licença ou termos de uso;
- data de acesso e período coberto;
- dicionário de variáveis;
- limitações, vieses e transformações realizadas.

Arquivos de dados ficam em `raw/` e `processed/`, são ignorados pelo Git e devem poder ser reconstruídos por instruções ou scripts documentados.
