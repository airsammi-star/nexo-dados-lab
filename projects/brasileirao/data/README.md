# Dados do projeto

## `raw/`

Contém os arquivos originais baixados da Base dos Dados. Esses arquivos não devem ser
alterados manualmente.

## `processed/`

Recebe bases derivadas, limpas ou agregadas. Todo arquivo deve poder ser reproduzido a
partir dos dados brutos e do código versionado.

Os formatos de dados estão ignorados no Git para evitar versionar cópias grandes ou
facilmente reproduzíveis.
