# Referências de repositórios públicos

Catálogo de repositórios para apoiar estudos, escolher projetos e observar diferentes formas de organizar soluções. A presença nesta lista não significa que todo o conteúdo esteja atualizado ou represente uma prática recomendada. Sempre verifique licença, dependências, data das alterações e qualidade metodológica antes de reutilizar qualquer material.

Última verificação: 20 de outubro de 2026.

## Como usar este catálogo

1. Consulte a referência para entender ideias, estrutura e raciocínio.
2. Refaça o problema com suas próprias decisões, explicações e dados permitidos.
3. Não copie um notebook inteiro para o portfólio.
4. Cite a fonte quando uma ideia, trecho ou abordagem influenciar seu trabalho.
5. Compare baseline, validação, métricas, análise de erros e limitações.
6. Nunca trate um projeto educacional como sistema pronto para uso bancário real.

## Fundamentos e trilhas de aprendizagem

### Python Data Science Handbook

Link: [jakevdp PythonDataScienceHandbook](https://github.com/jakevdp/PythonDataScienceHandbook)

Repositório com o texto e os notebooks do livro *Python Data Science Handbook*. Cobre principalmente IPython, NumPy, pandas, Matplotlib e scikit-learn. É uma boa fonte para aprender conceitos e consultar exemplos executáveis.

**Como aproveitar:** selecione capítulos alinhados à etapa atual do plano e reproduza os exemplos com dados próprios. Use-o principalmente para fundamentos de computação científica e análise tabular.

**Atenção:** o README informa que o material original foi escrito e testado com versões antigas do Python. Adapte APIs e dependências à versão atual em vez de copiar o ambiente antigo.

### Trilha de Estudos de Data Science

Link: [HinePo Trilha de Estudos de Data Science](https://github.com/HinePo/Trilha-de-Estudos-de-Data-Science)

Trilha extensa e continuamente construída que organiza técnicas de estudo e fontes sobre Python, Git, análise, engenharia e visualização de dados, machine learning, séries temporais, deep learning, NLP, sistemas de recomendação, implantação e MLOps.

**Como aproveitar:** use como mapa de consulta para encontrar um próximo assunto ou material complementar. A recomendação de equilibrar teoria e prática combina com a proposta do Nexo Dados Lab.

**Atenção:** é uma curadoria ampla, não uma sequência obrigatória. Escolha apenas o que contribui para a etapa atual e evite dispersão entre muitos temas avançados.

## Galerias e ideias de projetos

### AI Project Gallery

Link: [KalyanM45 AI Project Gallery](https://github.com/KalyanM45/AI-Project-Gallery)

Galeria que indexa projetos de machine learning, deep learning, IA generativa, visão computacional, web scraping, Power BI, recomendação e fluxos com agentes. O catálogo inclui exemplos de classificação, regressão e projetos de ponta a ponta.

**Como aproveitar:** use os títulos e domínios para gerar ideias e comparar como diferentes projetos são apresentados. Observe quais entregas são marcadas como ponta a ponta e investigue o que realmente foi incluído.

**Atenção:** amplitude não garante profundidade. Antes de usar uma referência, avalie documentação, licença, qualidade dos dados, validação, testes e análise de erros no repositório específico apontado pela galeria.

### Data Science and Machine Learning Projects with Source Code

Link: [durgeshsamariya Data Science Machine Learning Project with Source Code](https://github.com/durgeshsamariya/Data-Science-Machine-Learning-Project-with-Source-Code)

Lista curada de artigos, repositórios e kernels do Kaggle sobre análise de dados e machine learning. Reúne temas como séries temporais, segmentação de clientes, fraude, recomendação, classificação e visão computacional.

**Como aproveitar:** use para descobrir conjuntos de dados, perguntas e famílias de problemas. Escolha uma ideia e reconstrua a solução desde a definição da pergunta até a comunicação final.

**Atenção:** é sobretudo um índice de links externos, não um único projeto reproduzível. Avalie cada destino separadamente e não assuma que código, dados ou licença seguem o mesmo padrão.

## Referências ligadas ao Itaú

### Teste de data science do Itaú

Link: [Joaquimmnetto teste ds itau](https://github.com/Joaquimmnetto/teste-ds-itau)

Solução declarada pelo autor como baseada em um teste de ciência de dados usado em processo seletivo do Itaú. O trabalho foi desenvolvido em R e RMarkdown, com uso da API do scikit-learn por meio do pacote `reticulate`, e inclui conjuntos de dados no próprio repositório.

**Como aproveitar:** observe a decomposição do problema, a comunicação em RMarkdown e as decisões analíticas. Tente formular uma solução independente em Python apenas depois de compreender o enunciado e os dados.

**Atenção:** trate como solução histórica e não oficial. Não presuma que representa o processo seletivo atual, critérios atuais do banco ou resposta esperada. O repositório também contém artefatos locais de R, que não são um padrão de organização a reproduzir.

### Desafio Itaú vaga 99 Júnior

Link: [rafaellins itau desafio vaga 99 junior](https://github.com/rafaellins-itau/desafio-itau-vaga-99-junior)

Enunciado público de um desafio de programação para construir uma API REST que recebe transações e retorna estatísticas. O desafio original pede Java ou Kotlin com Spring Boot e destaca organização, testes, segurança, qualidade do código e evolução por commits.

**Como aproveitar:** use como referência de engenharia de software, desenho de API, testes e organização do histórico Git. É útil para compreender que profissionais de dados também precisam entregar software legível e confiável.

**Atenção:** não é um projeto de ciência de dados nem um exercício Python. Mantenha-o como referência complementar de engenharia, não como prioridade do ciclo inicial do plano.

### Hackathon Itaú Mackenzie

Link: [Rogerio mack Hackathon Itau Mackenzie](https://github.com/Rogerio-mack/Hackathon-Itau-Mackenzie)

Repositório de materiais de um hackathon Itaú e Mackenzie. Reúne amostras e metadados, informações do evento, capacitações e materiais sobre Python, SQL, visualização, storytelling, regressão e séries temporais.

**Como aproveitar:** use para observar a combinação entre preparação técnica, análise e apresentação. Os materiais sobre storytelling e séries temporais podem complementar projetos de portfólio.

**Atenção:** parte do conteúdo é específica do evento e alguns links externos podem envelhecer. Confirme disponibilidade e licença antes de incorporar dados ou materiais ao laboratório.

## Referências complementares do plano de estudo

### Microsoft Data Science for Beginners

Link: [Microsoft Data Science for Beginners](https://github.com/microsoft/Data-Science-For-Beginners)

Currículo introdutório baseado em projetos, organizado em dez semanas e vinte lições. Inclui conceitos, ética, preparação de dados, visualização e aplicações. É uma boa sequência inicial quando for necessário reforçar fundamentos.

### OSSU Data Science

Link: [OSSU Data Science](https://github.com/ossu/data-science)

Currículo aberto e extenso inspirado em uma formação acadêmica. É mais útil como mapa de aprofundamento de longo prazo do que como roteiro rápido para as primeiras 16 semanas.

### Hands On Machine Learning

Link: [ageron handson ml3](https://github.com/ageron/handson-ml3)

Notebooks que acompanham a terceira edição de *Hands-On Machine Learning*. Útil para fundamentos e exercícios com scikit-learn, Keras e TensorFlow. Para o início do plano, priorize os capítulos de machine learning clássico.

### Virgilio

Link: [virgili0 Virgilio](https://github.com/virgili0/Virgilio)

Mapa aberto de aprendizagem em ciência de dados e machine learning. Pode ajudar a localizar assuntos e referências, mas deve ser usado de forma seletiva para evitar excesso de trilhas simultâneas.

### IBM Data Science Best Practices

Link: [IBM Data Science Best Practices](https://github.com/IBM/data-science-best-practices)

Referência sobre práticas de engenharia para casos de ciência de dados, incluindo versionamento, testes, escalabilidade e monitoramento. É especialmente útil quando os projetos deixarem de ser apenas notebooks exploratórios.

### IBM Credit Risk with Jupyter

Link: [IBM Predict Credit Risk with Jupyter](https://github.com/IBM/predict-credit-risk-with-jupyter-on-cloud-pak-for-data)

Exemplo educacional de exploração, modelagem e implantação de uma solução de risco de crédito. Use para estudar o fluxo técnico e discutir limitações, explicabilidade e governança; não trate o modelo como política real de concessão de crédito.

### Banking Data Science Learning Path

Link: [ikhsannur1996 Basic Data Science](https://github.com/ikhsannur1996/basic-data-science)

Trilha prática de ciência de dados bancária com notebooks progressivos e dados sintéticos. Inclui fundamentos, estatística, risco de crédito, séries temporais, explicabilidade e tópicos de entrega. É útil para comparar ideias de projeto sem depender de dados bancários reais.

## Critérios para avaliar novas referências

Antes de adicionar um repositório ao catálogo, verifique:

- problema e público-alvo claramente explicados;
- licença de código, texto e dados;
- instruções de instalação e reprodução;
- atividade recente ou indicação clara da versão usada;
- fonte e significado dos dados;
- baseline, estratégia de validação e métricas;
- análise dos principais erros e limitações;
- testes e separação entre notebook e código reutilizável;
- privacidade, segurança, viés e explicabilidade quando aplicável;
- ausência de credenciais, dados pessoais ou materiais publicados indevidamente.
